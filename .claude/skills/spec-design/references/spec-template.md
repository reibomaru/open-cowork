# 仕様書テンプレート

SKILL.mdの「仕様書の構成」に対応する詳細テンプレート。
仕様書を新規作成する際にこのテンプレートをコピーして使う。

---

```markdown
# [システム名] 仕様書

## 1. 概要

### 1.1 目的
[このシステムが解決する課題]

### 1.2 対象ユーザー
[ペルソナの定義: 役割、技術レベル、利用コンテキスト]

### 1.3 システム概要
[LLMハーネスとしての全体像を1段落で]

---

## 2. ユーザージャーニー

### 2.x [ジャーニー名]

| 項目 | 内容 |
|------|------|
| ペルソナ | [誰が] |
| コンテキスト | [どんな状況で] |
| 要望（入力例） | 「[ユーザーが自然言語で入力する文の例]」 |
| 期待される振る舞い | [エージェントがどう動くか] |
| 成果物 | [何が得られるか] |
| 利用Skill | [skill-a], [skill-b] |

---

## 3. Skill定義

### 3.x [Skill名]

| 項目 | 内容 |
|------|------|
| 概要 | [1-2文で] |
| トリガー条件 | [いつ発動するか] |
| 利用Tool | [tool-a], [tool-b] |

**ワークフロー:**

1. [ステップ1]
2. [ステップ2]
3. [ステップ3]

**入出力:**

- 入力: [何を受け取るか]
- 出力: [何を返すか]

---

## 4. Tool定義

### 4.x [Tool名]

| 項目 | 内容 |
|------|------|
| 概要 | [1文で] |
| 依存外部システム | [API, DB, ファイルシステム等] |

**インターフェース:**

| パラメータ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| param_a | string | Yes | [説明] |
| param_b | number | No | [説明] |

**戻り値:** [型と構造の説明]

---
```
